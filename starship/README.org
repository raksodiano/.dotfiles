#+title: Starship Configuration
#+author: raksodiano

* Overview

Cross-shell prompt configuration for [[https://starship.rs/][Starship]], using a
two-line format with Nerd Font icons.

* Active Palette

=noctalia= -- a Gruvbox Material Hard variant generated by Noctalia.

* Palettes

| Palette                | Description                     |
|------------------------+---------------------------------|
| =noctalia=             | Active; Gruvbox Material tones  |
| =catppuccin_mocha=     | Catppuccin Mocha full palette   |
| =gruvbox=              | Original Gruvbox base colors    |

* Format

#+begin_example
╭ python directory git_branch git_status kubernetes cmd_duration
╰─❯
#+end_example

* Modules

| Module         | Notes                                  |
|----------------+----------------------------------------|
| =python=       | Shows virtualenv when active           |
| =directory=    | Truncated to 3 components, fish-style  |
| =git_branch=   | With branch icon                       |
| =git_status=   | Full status with Nerd Font symbols     |
| =kubernetes=   | Shows context and namespace            |
| =cmd_duration= | Shows command duration in milliseconds |

* Directory Substitutions

Documents, Downloads, Music, and Pictures are replaced with Nerd Font icons.
