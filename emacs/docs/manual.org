#
#  Este documento explica la configuración de Emacs que se mantiene en el
#  repositorio `~/.dotfiles/emacs`.  Todo el código está distribuido en
#  dos carpetas:
#  - `init.d/core/`: dependencias y bases que todos los módulos usan.
#  - `init.d/modules/`: dominio‑saldos (git, langs, org…).
#  La carga se hace con `init.el` en orden explícito; no se puede
#  confiar en el nombre de los ficheros.
#
#  El atajo maestro es `SPC` (meow).  La librería `which-key` provee
#  descripciones concisas.
#
#  Los módulos están diseñados para funcionar con Emacs 31.1.
#
#  Este archivo se abre con `SPC h r`.
#
#  ---
#  ## Instalación
#
#  ```bash
#  # 1. Instalar dependencias (Arch / CachyOS)
#  paru -S emacs git-delta ripgrep fd
#  # 2. Enlazar la configuracion con Stow
#  cd ~/.dotfiles && stow emacs
#  # 3. Lanzar Emacs (el primer arranque instalará los paquetes automáticamente)
#  emacs
#  ```
#

#  ## Estructura de Carpetas
#  ```org
#  ~/.config/emacs/
#  ├── early-init.el           ; Parche de paquetes, GC y rutas XDG
#  ├── init.el                  ; Punto de entrada, carga módulos
#  ├── init.d/
#  │   ├── core/                ; Fundamentos (core)
#  │   │   ├── defaults.el       ; Codificación, GC, rutas
#  │   │   ├── keys.el             ; Meow + leader + which-key
#  │   │   ├── ui.el              ; Tema, modeline, tabs, workspaces
#  │   │   ├── buffers.el         ; completado, dired, historial
#  │   │   └── editing.el         ; snippets, multi‑cursor, formateo, TS
#  │   └── modules/                ; dominios opcionales
#  │       ├── git/                ; magit, magit‑delta
#  │       ├── langs/              ; lsp, treesit, languagetool
#  │       ├── org/                ; org, capture, journal, hugo, roam…
#  │       ├── feeds/              ; elfeed
#  │       ├── media/              ; pdf, epub, calibre
#  │       ├── ai/                ; gptel, ellama, agent‑shell, aidermacs
#  │       ├── tools/              : detached, pass, treemacs, docker, keycast
#  │       └── term/                ; vterm
#  └── assets/                    ; sonidos, imágenes, plantillas LaTeX
#  ```

#  
#  ## Instrucciones de uso
#  1. **Cambios en la configuración** – cada vez que editas un
#     archivo .el en la carpeta `init.d`, guarda y reinicia Emacs.
#  2. **Actualizar paquetes** – ejecutar `M-x package-refresh-contents`
#     y luego `M-x package-install-selected-packages`.
#  3. **Instalar paquetes faltantes** – se detectan automáticamente
#     al arrancar; fib.
#  4. **Contribuciones** – crear branch, hacer pull request.
#  
#  ## Estado de los paquetes externos
#  - `hugo`:  no instalado (debe apuntar a un sitio Hugo).
#  - `gopls`:  falta binario.
#  - `pass`:  binario disponible (pero no se usa en esta caja).
#  - `delta`:  falta binario.  Si lo instalas, Magit’ll use
#               delta.

#  Este manual pretende ser la guía de referencia para el usuario final,
