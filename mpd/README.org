#+title: MPD Configuration
#+author: raksodiano

* Overview

MPD (Music Player Daemon) configuration for local music playback via PipeWire,
with rmpc as the client interface.

* Server Settings

| Setting            | Value                       |
|--------------------+-----------------------------|
| Bind address       | =$XDG_RUNTIME_DIR/mpd.sock= |
| Music directory    | =~/Music=                   |
| Log level          | =notice=                    |
| Auto-update        | =yes= (depth 5)             |
| Follow symlinks    | =no=                        |

* Runtime Files

All runtime files are kept outside the repository:

- Database: =~/.local/share/mpd/database=
- Playlists: =~/.local/share/mpd/playlists=
- State: =~/.local/share/mpd/state=
- Logs: =~/.cache/mpd/log=
- PID: =~/.cache/mpd/pid=

MPD does not create the parent directories. Create them before the first start:
#+begin_src bash
mkdir -p ~/.local/share/mpd/playlists ~/.cache/mpd
#+end_src

* Audio Output

PipeWire via PulseAudio interface:
#+begin_example
type: pulse
name: PipeWire
#+end_example

* Client

[[https://github.com/djrm/rmpc][rmpc]] is the terminal client, configured with Vim
keybindings and Gruvbox Material Hard theme.

The client reaches the Unix socket through =MPD_HOST=, exported in
=~/.bashrc=; the =address= in =config.ron= is only a fallback.
